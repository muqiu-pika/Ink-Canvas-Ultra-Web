# 更新日志

## 最新版本：26.9.5

### V26.9.5
- 更新软件版本号为 v26.9.5
- 完善插件更新与软件版本限制提示
  - 已安装插件有新版本、但新版要求的主程序版本高于当前软件版本时，新版本号标红并加删除线，下方提示"软件版本号过低，请更新到 X 后再更新本插件"
  - 「更新」按钮禁用置灰，与插件工坊可安装区的策略一致
  - 下载前同步做版本兼容性拦截，避免下载后安装失败
- 下载优化：改为多源自动回退，并让 GitHub 代理覆盖全部直连源
  - 任一源成功即返回，全部失败才判定为网络问题
  - 超时分段控制：首字节 10 秒、整体 15 秒（安装包除外）、传输停滞 30 秒
- 重写「截图已成功」窗口：由固定弹窗改为独立窗口并美化 UI
- 修复一些问题
  - 修复 PPT 相关功能的多个窗口串行弹出问题
  - 置顶状态改为从主窗口继承，修复有概率「文件对话框被挡住」的问题

#### Ink-Canvas-Ultra-Plugin 更新（跟随 V26.9.5）
- 「工具栏按钮排序」插件更新至 1.0.2
  - 新增「删除工具栏按钮」功能（「工具」按钮除外），删除需二次确认，可恢复默认
  - 修复插件打包失败，完善 CI 打包上传
  - 最低主程序版本升至 v26.9.5

### V26.9.4
- 更新软件版本号为 v26.9.4
- 新增「截图后复制到剪贴板」
  - 设置中新增「截图后复制到剪贴板」开关，开启后自动截图保存的 PNG 会同时写入剪贴板

- 修复导入视频后缩略图一直停留在占位图的问题：视频首帧提取改为在界面线程等待媒体打开后截取

- 优化「导入文档」功能
  - 改为后台线程预解码、分批调度，加快大批量文档导入，界面更流畅
  - 添加翻页保护与内存护栏，避免大文档导入时卡顿/占用过高
- 修复一些问题
  - 修复 PPT 自动跳转至上次关闭位置失败的问题
  - 修复选中照片后 8 个点的触摸拖拽失效的问题

### V26.9.3
- 更新软件版本号为 v26.9.3
- 自动更新优化
  - 版本检测改为双源：GitHub raw 主源 + jsDelivr CDN 兜底，主源不可达时自动回落到 CDN
  - 请求超时从 15 秒缩短到 8 秒，失败更快回落，减少卡顿
  - 合并并发版本检测：启动/设置页/定时器同时触发时只发一次网络请求
  - 多源全部失败才记一条日志，避免超时异常刷屏
- 快捷键体系增强（配合「自定义快捷键」插件）
  - 新增浮动工具栏功能快捷键：插入媒体、倒计时、随机抽选、随机选人、保存/打开/播放墨迹（Alt+M / T / R / P / I / O / W）
  - 画笔切换快捷键 Alt+1~Alt+5：修复此前按键无效的问题，并纳入自定义快捷键体系
  - PPT 放映翻页/退出快捷键（PageDown / PageUp / Escape）由硬编码改为可被插件修改
  - 支持绑定无修饰键的组合键（如单独的 PageDown / Escape）
  - PPT 滚轮翻页受「自定义快捷键」中翻页动作的启用状态约束
  - 优化粘贴快捷键：放映 PPT 时不处理、主窗口隐藏（Alt+V）时不响应、并补充浮动栏模式
- 日志写入修复：加入线程/进程同步锁，修复"文件正被另一进程使用"的异常
- PPT 连接优化：仅当 PowerPoint / WPS 演示进程存在时才尝试连接，避免反复抛 COM 异常刷屏
- 浮动栏置顶修复：修复跨线程访问导致置顶逻辑未真正执行的问题
- 修改 GitHub Actions 产物名：改为 Ink.Canvas.Ultra.V{版本}.zip
